# Nexus Neural Ecosystem v4.5.0

El ecosistema **Nexus** (Red Inteligente) es una red neural distribuida y autónoma diseñada para descentralizar el comercio, la inteligencia artificial y la gobernanza digital.

## 🧠 Arquitectura del Sistema

El sistema se divide en cuatro componentes críticos interconectados:

1.  **Arquetipo API (Núcleo)**: El cerebro del sistema. Gestiona la lógica de negocio proactiva, el motor de decisiones **Albedrío** y el sistema de defensa **Sentinel**.
2.  **Blockchain Neural (Registro)**: Un libro mayor P2P inmutable que ancla cada "sinapsis" (transacción o evento) mediante algoritmos de consenso neural.
3.  **Nexus Mobile (Gestión)**: Interfaz premium para la gestión de activos, gobernanza DAO y monitoreo de salud de red en tiempo real.
4.  **Nexus PC (Infraestructura)**: Motor de minería de alto rendimiento que proporciona la masa computacional necesaria para la red, recompensando a los nodos con tokens **NEX**.

## 🛠️ Tecnologías Core

- **Backend**: NestJS, Prisma ORM, PostgreSQL.
- **Frontend**: Next.js 14, Tailwind CSS, Lucide Icons, Framer Motion.
- **Protocolo**: WebSockets P2P, Criptografía SHA-256.
- **IA**: Albedrío Rules Engine (Proactividad Determinística).
- **Seguridad**: Sentinel Defense System (DDoS & Anomaly detection).

## 🚀 Instalación y Despliegue

El ecosistema está completamente dockerizado para facilitar su portabilidad.

```bash
# Clonar el repositorio
git clone https://github.com/Alexstones/red-inteligente.git

# Levantar todo el ecosistema con Docker Compose
docker-compose up --build
```

## 💎 Economía Neural (Token NEX)

El token **NEX** es el combustible de la red. Su valor se calcula dinámicamente mediante el **Oráculo de Mercado**, basado en la utilidad real de la red: `Valor = (Nodos * 0.1) + (Sinapsis * 0.01)`.

## 🛡️ Seguridad Sentinel

La red está protegida por la capa **Sentinel**, que monitorea el estrés neural y puede poner nodos en cuarentena automáticamente si detecta comportamientos maliciosos o inundaciones de sinapsis.
